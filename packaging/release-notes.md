| **Windows 10 / 11** | [vidkeep-setup.exe](https://github.com/RootX22/vidkeep/releases/latest/download/vidkeep-setup.exe) | Run it, then open vidkeep from the Start menu |
| **Mac (Apple silicon, M1 or newer)** | [Vidkeep-mac.zip](https://github.com/RootX22/vidkeep/releases/latest/download/Vidkeep-mac.zip) | Unzip, move Vidkeep to Applications |
| **Firefox add-on** | [vidkeep-firefox.zip](https://github.com/RootX22/vidkeep/releases/latest/download/vidkeep-firefox.zip) | Needs the command line version, see the README |

Everything vidkeep needs (ffmpeg and a JavaScript runtime) is inside. Free, no account, no ads.

**First launch.** vidkeep is not signed with a paid certificate yet, so the system asks once:
- Windows: on "Windows protected your PC", click **More info**, then **Run anyway**.
- Mac: right-click Vidkeep in Applications, choose **Open**, then **Open** again. If macOS still
  refuses, open System Settings → Privacy & Security and click **Open Anyway**.
