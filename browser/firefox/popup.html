Connect vidkeep

This add-on hands downloads to the vidkeep program on your computer. Install it once:

  1. brew install ffmpeg deno (or your package manager)
  2. pipx install git+https://github.com/RootX22/vidkeep
  3. vidkeep browser install

Then open this button again. More help
